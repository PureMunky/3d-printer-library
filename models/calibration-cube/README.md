# XYZ calibration cube

A 20 mm cube with X, Y and Z engraved on the matching faces. Print it with
your normal settings and measure each axis with calipers (X/Y above the 0.4 mm
bottom chamfer).

- X/Y off by a consistent amount → slicer "XY hole/contour compensation" or flow.
- Z off → layer height/first-layer Z-offset.

See [PRINT.md](PRINT.md) for generated print notes.
